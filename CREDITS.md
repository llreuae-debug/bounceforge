## 3. Audio & Music Attribution

1. **Procedural Synthesizers**:
   - All sound synthesis (Grand Piano, Music Box, Marimba, 8-bit Synth, Chiptune, Bell Glock, Kalimba, Soft Pad, Strings, Anvil, Water Drop, Woodblock, Sine Pop, Sub Bass 808) is synthesized procedurally in real time using the native browser Web Audio API (`AudioContext`, `OscillatorNode`, `GainNode`, `BiquadFilterNode`, `ConvolverNode`).
2. **Public Domain Melodies**:
   - Every classical melody provided in the library (*Fur Elise*, *Ode to Joy*, *Canon in D*, *Mozart Sonata in C*, *Swan Lake*, *Brahms Lullaby*, *Greensleeves*, *Vivaldi Spring*, *Bach Minuet in G*, *Turkish March*, *Gymnopedie No. 1*, *The Entertainer*, *Clair de Lune*, *Flight of the Bumblebee*) is verified to be in the **Public Domain worldwide** (composers deceased > 70–100 years).
   - All arrangements, MIDI transcriptions, note velocities, and layout solving are original procedural creations of BounceForge.
